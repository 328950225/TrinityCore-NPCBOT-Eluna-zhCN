## 🌟 项目简介 (Introduction)

本仓库是基于 **TrinityCore 3.3.5a** 分支的深度增强整合版。我们在保留核心稳定性的基础上，完成了 **NPCBots** 与 **Eluna Lua Engine** 的深度融合。

### 💎 整合版特色 (zhCN Edition)

* **一站式部署**：集成 NPCBots 机器人系统与 Eluna 引擎，无需手动处理繁琐的源码冲突。
* **深度汉化适配**：针对中文玩家与开发者，对 NPCBot 交互菜单及核心指令进行了细致的汉化处理。
* **海量脚本库**：内置超过 **4000+** 个 Lua 与 C++ 脚本示例，涵盖了全账号专业技能同步、各种特色玩法逻辑等。
* **开发者友好**：提供大量中文注释的脚本案例，是学习 TrinityCore 开发的理想资源。

---

## 🚀 核心组件 (Core Components)

* **TrinityCore (3.3.5)**: 行业标准级别的开源 MMORPG 框架。
* **[NPCBots Mod](https://github.com/trickerer/Trinity-Bots)**: 强大的机器人助手，支持 AI 战斗、装备养成与组队副本。
* **Eluna Engine**: 高效的 Lua 脚本接口，让游戏逻辑扩展变得简单快捷。
